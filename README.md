# Abdulgamid Parfum

Многостраничный сайт магазина нишевой парфюмерии в Волгограде: каталог, корзина, заявка в WhatsApp и админка для правки товаров.
Сайт на чистых HTML + CSS + JS без сборки. Серверная часть (только для админки) это одна функция Netlify.
Данные и фото взяты из Instagram @abdulgamid_gamdullaev (25.09.2026).

## Выложить на Netlify через GitHub

1. Загрузите **все файлы и папки** этого проекта в репозиторий GitHub (кнопка «Add file → Upload files»). Важно, чтобы в репозитории были `netlify.toml`, `package.json`, `admin.html` и папка `netlify/functions/api.mjs`. В веб-загрузке GitHub не больше 100 файлов за раз, поэтому фото (`img/p/`, 104 файла) загрузите отдельным заходом.
2. В Netlify: **Add new site → Import an existing project → GitHub**, выберите репозиторий. Поля сборки оставьте пустыми: `netlify.toml` уже всё задаёт (публикуется корень, функции берутся из `netlify/functions`).
3. **Обязательно задайте пароль админки:** Site configuration → Environment variables → Add a variable, имя `ADMIN_PASSWORD`, значение ваш пароль (длинный, лучше не короче 12 символов). Затем Deploys → Trigger deploy → **Deploy site**, чтобы пароль подхватился.
4. Откройте `https://ваш-сайт.netlify.app/admin.html`, введите пароль.

Хранилище каталога (Netlify Blobs) отдельно включать не нужно, оно работает на любом сайте Netlify.

## Как пользоваться админкой

- **Цены:** впишите прямо в строку аромата, на 3, 5, 10 мл и флакон. Пустое поле значит «цена по запросу». Можно выбрать галочками несколько ароматов и задать цену сразу всем («Применить цены»).
- **Нет в наличии:** переключатель «В наличии». Карточка получит отметку и кнопку «Узнать о наличии», в корзину добавить нельзя, такие ароматы уходят в конец каталога.
- **Скрыть с сайта:** переключатель «На сайте». Аромат остаётся в админке, но не виден посетителям.
- **Изменить:** кнопка «Изменить» открывает окно: название, бренд, тип (распив или масло), пол, семейство, описание, ноты, цены, фото, «Можно брать вслепую». Там же «Удалить аромат».
- **Добавить:** «+ Добавить аромат». Фото загружается с компьютера или телефона и сжимается автоматически.
- **Сохранить:** все правки копятся в окне, и на сайт уходят кнопкой **«Сохранить на сайт»** внизу. Изменения видны сразу, пересборка сайта не нужна. Если закрыть окно без сохранения, браузер предупредит.
- **Дополнительно** (внизу): скачать копию каталога (JSON), вернуть предыдущее сохранение, вернуть исходный каталог из `js/data.js`.

Пока в админке ни разу не нажимали «Сохранить», каталог берётся из файла `js/data.js`. После первого сохранения каталог живёт в хранилище Netlify, а `js/data.js` остаётся запасным вариантом (и источником для «Вернуть исходный каталог»). Новые выкладки сайта из GitHub правки из админки не затирают.

## Безопасность

Вход один, по паролю из `ADMIN_PASSWORD`. Пароль не хранится в файлах. Сессия 12 часов (защищённая cookie), после 8 неверных попыток с одного адреса вход закрывается на 15 минут. Смена пароля в Netlify (и повторный деплой) сразу разлогинивает всех. Админка не индексируется поисковиками. Открытая часть (`/api/catalog.js`) отдаёт только видимые ароматы.

## Страницы и файлы

| Файл | Что |
|---|---|
| `index.html` | Главная: первый экран (четыре флакона столбиком, при прокрутке по очереди открывают крышки), «сколько это 3 / 5 / 10 мл», подборка «вслепую», авторский Attar Al-Janna, бренды, фото заказов |
| `catalog.html` | Каталог: поиск, фильтры (пол, семейство, бренд, масла), сортировка, «Показать ещё» |
| `perfume.html?id=...` | Страница аромата: ноты, выбор объёма, «В корзину», «Заказать сразу в WhatsApp» |
| `podbor.html` | Подбор аромата: кому (мужской/женский/унисекс) и любимые ноты — 10 групп, около 50 нот. Живой список подходящих ароматов, можно сразу в корзину |
| `admin.html` | Админка (`js/admin.js`, `css/admin.css`) |
| `netlify/functions/api.mjs` | Серверная часть: вход, каталог, загрузка фото |
| `js/data.js` | Каталог по умолчанию (115 ароматов) и настройки магазина |

В конце каждой страницы сайта: форма заявки (имя, телефон, название духов, объём) и подвал. Форма собирает сообщение и открывает `https://wa.me/79370994042?text=...`. Имя и телефон нигде не сохраняются. Корзина хранится в `localStorage` браузера (`ap-cart`).

## Правка без админки

**Аромат** (`js/data.js`): одна строка = один аромат. Поля: `id`, `b` бренд, `n` название, `t` (`s` распив и флакон, `o` масло), `g` пол (`m` / `w` / `u`), `fam` семейство, `tags`, `y` год, `c` страна, `d` описание, `nt` ноты `{t,h,b}` или `na` одной строкой, `p` файл фото из `img/p/`, `ig` код поста, `bl` (1 = «можно брать вслепую»), `sg` (1 = авторский), `pr` цены `{"3":390,"5":590,"10":990,"full":4500}`, `out` (1 = нет в наличии), `hide` (1 = скрыт). Порядок «Новые» считается по `dt`.

**Объёмы**: `SHOP.volumes` в начале `js/data.js` (сейчас 3, 5, 10 мл и флакон; цифры «пшики / на сколько хватит» из поста магазина).

**Номер WhatsApp**: в `js/data.js` (`SHOP.phone`) и в HTML. Шапка, блок заявки и подвал продублированы в четырёх страницах, поэтому номер `79370994042` / `8 937 099-40-42` меняйте поиском по всем `.html`.

**Ноты для подбора** (`podbor.html`): список групп и нот — `NOTE_GROUPS` в начале `js/pages.js`. Каждая нота ищется как начало слова в нотах/описании/названии аромата (без учёта регистра и «ё»), поэтому подбор работает для любого аромата из `js/data.js` или добавленного в админке — отдельно ничего размечать не нужно. Добавить ноту: впишите `['ключ', 'Подпись', ['основа-слова']]` в нужную группу.

**Флаконы первого экрана** (`index.html`, блок `.hero__stack`): Baccarat Rouge 540, Lost Cherry, Erba Pura, Althaïr. Фото — официальные снимки брендов с прозрачным фоном, обрезаны по контуру, лежат в `img/hero/`. Каждый флакон — один PNG, показанный двумя слоями: корпус и крышка. В `style` у `.hbot`: `--ar` — ширина/высота снимка, `--cut` — где кончается крышка (в % высоты снимка). Карточка справа связана с ароматом через `data-id` (id из каталога), бренд и название подставляются из каталога сами. Чтобы заменить флакон: положите прозрачный PNG в `img/hero/`, поменяйте `src` у обеих картинок, `--ar`, `--cut`, `data-id` и описание в карточке.

**Цвета и шрифты**: токены в начале `css/style.css`. Описание дизайна: `DESIGN.md`, контекст: `PRODUCT.md`.

## Что важно знать

- Цен, условий доставки, адреса и часов работы в Instagram нет, поэтому на сайте их нет. Цены теперь вносятся в админке.
- Фото ароматов взяты из постов магазина (часть постов совместные с @king_parfume__, часть кадров рекламные от брендов). Со временем лучше заменить своими съёмками через админку.
- Каждая страница сайта при открытии один раз обращается к функции за живым каталогом (`/api/catalog.js`). На бесплатном тарифе Netlify лимит 125 000 запросов к функциям в месяц, для небольшого магазина этого хватает.
- Локально (двойным щелчком по файлу) сайт показывает каталог из `js/data.js`, а админка честно пишет, что работает только на Netlify.
- Для превью-картинки в соцсетях (`og:image`) нужен адрес сайта после публикации, поэтому она не добавлена.
- Переходы между страницами (`@view-transition`) работают в Chrome / Edge / Safari 18+, в остальных браузерах страницы открываются обычным образом.
